# ChiTuBox Slicer - A Resin Slice On A Printer You Run

## Closing Notes for ChiTuBox Slicer

Treat ChiTuBox Slicer as the slice for a resin printer you already operate, not as a tray of random meshes. Open ChiTuBox when the part is the one you meant. Keep the plate simple. Move failed slices out of the working folder. Let old experiments stay quiet.

If you change chairs, take the project with you and confirm the printer. If you show a teammate, show them the preview in ChiTuBox first. After that, ChiTuBox Slicer usually needs almost no explanation.

The next job should open the same file. The printer name should still match the machine at this desk.

The plate you slice should still be the part you meant. If supports were leftover from another mesh, rebuild them in ChiTuBox before you send. ChiTuBox Slicer is easier when the project sits next to the model.

## Advanced Use Cases for ChiTuBox Slicer

**Scenario 1: A miniature** - Open the part in ChiTuBox Slicer, raise it, and check supports in ChiTuBox before you slice.
If a thin bit has no support, fix that on the plate, not after a failed print.
**Scenario 2: A lab vat** - Use the profile that belongs to this printer.
Do not send a job meant for another machine.
**Scenario 3: A revised model** - Date the project so the slice matches the file you just exported.
ChiTuBox Slicer should open that revision, not last week's mesh.
**Scenario 4: Shared bench** - Close ChiTuBox when you leave so the next person starts from their own file.
Keep your project in your account.

**Is ChiTuBox Slicer hard to learn?**  
No. ChiTuBox Slicer is a part, a plate, and a preview. ChiTuBox does not need a second tool for that pass.
**Can ChiTuBox Slicer help on an older laptop?**  
Yes, for a normal resin part. A heavy mesh may ask you to hide extra copies on the plate.
**Does ChiTuBox Slicer need a complex account system?**  
No. ChiTuBox Slicer can start from a local project on the PC you use.

Yes. Each person can keep a ChiTuBox folder of their own.

ChiTuBox Slicer fits best on the PC next to the resin printer you already run.

## Quick Start with ChiTuBox Slicer

1. **Open ChiTuBox Slicer** - On the PC next to the resin printer you run.
2. **Load the part** - Use a model you are allowed to print.
3. **Place it** - Let ChiTuBox sit the piece where the supports make sense.
4. **Preview** - Look at the plate before you slice.
5. **Save the project** - Keep it beside the model in the folder you named.
6. **Send only then** - The vat should be the one you operate.
7. **Close** - Leave ChiTuBox so the next person starts from their own file.
